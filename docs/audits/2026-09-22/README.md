Дополнение основано только на предоставленном 43-страничном PDF и отдельно помеченных проектных рекомендациях. Оно подтверждает, что preferences, групповой выбор, markup, reference images и сочетание некоторых услуг уже показаны у конкурента; не следует называть их уникальностью PicchuSpot. Руководство не устанавливает наш Camera2 contract, тарифы, SLA или платёжную архитектуру. Исходный PDF и чужие визуальные материалы не публикуются в репозитории.
